# BuffedMons
A datapack buffing certain Pokémons.

The buffs needs the thematically make sense and make them viable in UU/OU/Uber under Gen 9 standards. 
<br>
Also I like the idea of a Pokémon group so if 1 in the group out buff the rest will too.

Feel free to drop any suggestions as an issue, I need more ideas.

### Requirement

1. [Cobblemon](https://modrinth.com/mod/cobblemon) 1.8 or newer

1. [Mega Showdown](https://modrinth.com/mod/cobblemon-mega-showdown) 1.0+1.8+1.21.1-BETA or newer
